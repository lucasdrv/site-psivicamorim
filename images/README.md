# Pasta de imagens

Coloque aqui as suas fotos (JPG, PNG ou WebP).

Depois, no arquivo da seção em `content/`, troque o campo `arquivo` pelo caminho da foto. Exemplo:

```js
imagem: {
  arquivo: "images/sobre.jpg",
  descricao: "Foto da Ana Silva em seu consultório"
}
```

Dicas:
- Use nomes simples, sem espaços nem acentos (`sobre.jpg`, `consultorio.jpg`).
- Prefira imagens com até ~500 KB para a página carregar rápido.
- Mantenha as letras maiúsculas/minúsculas exatamente iguais no nome do arquivo e no caminho.
